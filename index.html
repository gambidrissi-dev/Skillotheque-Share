Skillothèque

Gestionnaire de skills pour macOS.

Version —
⬇ Télécharger pour macOS

macOS 13 (Ventura) ou plus récent · Apple Silicon & Intel

  • Un dépôt git, tes skills — chaque skill vit une seule fois (fichier SKILL.md avec frontmatter), synchronisée par git plutôt qu'éparpillée par outil.
  • Cinq destinations intégrées — Hermes, Claude Code, Syntax, Gemini CLI, Codex CLI. Masquables individuellement si tu n'as pas l'outil, jamais supprimables.
  • Copiée où il faut — une skill dit elle-même pour quelles cibles elle est active (targets:) ; l'app la place au bon endroit sur le disque, jamais écrasée si une skill du même nom existe déjà dans la catégorie.
  • Détection de divergence — si le fichier réel a été modifié à la main depuis la dernière copie, l'app le signale plutôt que d'écraser silencieusement.
  • Exemples inclus — quelques skills livrées à la création du dossier, pour ne pas partir d'une page blanche.
  • Interface bilingue — français / anglais, un bouton pour basculer ; le contenu des skills, lui, reste tel qu'écrit par son auteur.

1. Décompresse le zip, glisse Skillotheque.app dans Applications.
2. Au premier lancement, macOS affiche « développeur non identifié » — fais clic droit → Ouvrir, puis confirme. C'est normal, l'app n'est pas distribuée via l'App Store.
3. Les mises à jour suivantes se font automatiquement depuis le menu Skillotheque → Rechercher des mises à jour…
